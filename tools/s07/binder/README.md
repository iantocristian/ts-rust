# S07 binder graph observations

The oracle is built from a fresh export of pinned Corsa commit
`1f70213d4922b434345f639b441681e470c7cfc1`. The bridges expose fields and private
payload discriminants only. Native parsing and binding run outside the observer;
only those native calls have panic recovery. An observer failure, malformed
record, aborted process or deadline failure invalidates capture.

`generate_syntax.py` generates accessors for all 192 schema payloads and their
495 non-header source fields. It does not generate parser or binder behavior.
`--check` compares formatted generated bytes with the checked-in adapters.

Each parser-entry request performs six ordered stages:

1. `parse`
2. `parsed_graph`
3. `bind`
4. `bound_graph`
5. `repeat_bind`
6. `repeated_graph`

A native panic terminates that request with its raw bytes and stage. It never
removes the request or its primary physical row. Graph stages cannot report a
native panic. Unknown panic classes fail closed. Repeated binding must produce
an identical graph within the same runtime, including raw names and diagnostics.

The source record registers the source node, ordered ambient patterns, ordered
diagnostic roots, source indicators and global-export table. A FIFO queue then
walks each node, syntax list, raw node/text slice, symbol, symbol table,
declaration slice, flow and flow list. IDs start at one independently for each
record domain; zero means nil. References register in the explicit field order
in `graph.go` and `graph.rs`. Node payload fields follow the frozen source schema.
Unordered symbol tables are traversed in raw-byte key order by the observer.
Production iteration is untouched. List contents and diagnostic collections
retain their order and multiplicity. The final record closes every domain with
an exact count; dangling edges and repeated/missing IDs are rejected.

Node records contain the bound header, parent, complete syntax payload, eager
JSDoc roots, symbol/local symbol, locals, next container and every flow side
field. Symbol records include declaration headers, complete declaration
capacity contents, parent/export links and member/export tables. Source records
include bind state, counts, indicators, ambient patterns and complete diagnostic
arguments, message chains, related information and flags. Nil and allocated
empty lists/tables remain distinct.

Raw slices additionally record visible storage aliasing. Connected overlapping
exported ranges share a backing-group ID; offsets are relative to the first
visible element. Declaration capacity is exported by the source API, so its
whole capacity participates. AST node/text slices expose their current ranges.
The observation excludes inaccessible allocator prefixes and suffixes. Empty
visible ranges have no element-level backing group; their non-nil header
identity is still retained. Pointer arithmetic exists only in the Go observer
and never appears in compared output.

The pinned binder creates each synthetic switch-clause/reduce-label payload
immediately for one fresh flow node. Its identity is `(owner FlowId, payload
kind)`, with the actual source header also observed. The Go observer rejects a
payload shared by multiple owning flows. This is a binder-producer invariant,
not a general checker graph representation. A future producer sharing such
payloads requires explicit synthetic arena identity before it can use this
representation.

Only two exact source-generated name components use graph identity: attributed
ambient module `pattern@NodeID`, and private class `#SymbolID`. Both observers
verify the literal spelling against the already-assigned runtime ID using
load-only getters, then retain the raw bytes alongside the canonical reference,
literal prefix and suffix. Ordinary names and every diagnostic byte remain
exact. Comparison reports retain qualification occurrences and raw-exactness
bits; unknown forms cannot receive the normalization.

Frames have the S06 16 MiB request and 1 MiB response limits. Large graph records
are split into ordered 128 KiB JSON-byte fragments with a strict 128 MiB logical
record bound. Fragment count, byte size and order are checked before graph
validation. Absolute per-request deadlines include writes, buffered reads and
JSON decoding; progress does not renew them.

`binder-cases.json` and `binder-requests.json` retain the complete S06 input
expansion: 12,829 physical/library rows and 22,343 parser-entry requests.
`binder-probes.json` stores independently observed Go reached-stage counts and
per-request outcome-shape references. Deduplicating identical ordered outcome
shapes does not remove a request or field. Supplemental requests have a separate
manifest and denominator. A primary row passes only when every required variant
matches. Primary parity cannot certify the supplemental or resolver groups.

Commands:

- `python3 scripts/s07_binder.py freeze --write-manifest`: regenerate Go inputs,
  independently preflight every full graph, and write reviewed obligations.
- `python3 scripts/s07_binder.py e1`: verify obligations, build both adapters,
  exercise protocol corruption checks, then compare every frozen request.
- `python3 scripts/s07_binder.py smoke`: compare only the explicit small source
  discriminators; no primary metric is published.
- `python3 scripts/s07_binder.py test`: run Go observer tests and corruption,
  missing-variant, name-normalization and deadline tests.
