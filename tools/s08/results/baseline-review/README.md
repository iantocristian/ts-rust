# S08 native baseline authority observations

Interpretation and pending decisions:
[`docs/S08-P0-baseline-review.md`](../../../../docs/S08-P0-baseline-review.md).
This is a diagnostic archive, not an E2 producer or an approved expected-output
manifest. No Rust checking result is inferred from it.

`observed-inventory.json` is the verified full-capture review: all named failures,
skips, filename exclusions, source-closure discrepancies and measured counts.
It is generated by `scripts/s08_baselines.py --review-capture`; its hashes join
it to the exact full capture and reviewer source. It must not be consumed as a
list of permitted divergences.

`recorded-results.tar.xz` preserves these runs without dropping failed rows:

- `baselines-smoke-01`: original five-source trial, four completed and one native
  removed-option failure. The Python source fingerprint is retained, but its
  original Python source snapshot was not saved. All compiled Go overlays are
  present. This early diagnostic is superseded by the final smoke below.
- `baselines-full-01`: all 10,728 frozen variants, including 1,315 skips and 34
  failures; complete raw requests, baselines, walker pulls and diagnostic payloads.
  Source snapshots were copied and hash-verified before the subsequent tooling
  edits. The current review additionally checks inputs/diagnostics of skipped
  rows; it does not rewrite the original report.
- `baselines-duplicate-input-01`: isolated reproduction of the duplicate-file
  discrepancy using the original native constructor; no cross-case cache state.
- `baselines-outcome-contract-01`: five-source smoke, including compiled
  checks distinguishing empty content, `NoContent`, and arbitrary invalid UTF-8
  bytes. The same four cases completed and the same removed-option case failed.
- `baselines-final-smoke-01`: final observer, also propagating a nonfatal Go
  test failure even if a row reaches its end. Its observations are byte-identical
  to the outcome-contract smoke.

The final smoke also fixes an observer serialization corner case: an empty
content baseline must serialize `text_hex: ""`, rather than omit it. No content
outcome in the full capture omitted that field, so this did not change the
recorded full-capture counts or bytes. All native source hooks are observational;
none modifies `upstream/` or writes reference baseline files.

`manifest.json` lists every archive member's size and SHA-256, plus the archive
hash. The archive includes commands, stdout/stderr, request/source fingerprints,
actual overlay source and source snapshots for all but the first smoke. The
snapshots include frozen S07/S08 data; repeated copies preserve each capture's
source closure. The packaging script is included. Native overlays contain their
original absolute paths; reproduce with new output paths rather than running an
archived overlay unchanged. The pinned upstream tree/toolchains are required.

Reproduce the full capture and review from the unchanged frozen inputs:

```sh
python3 scripts/s08_baselines.py --output target/s08/baselines-review
python3 scripts/s08_baselines.py --review-capture target/s08/baselines-review --output target/s08/baselines-review-inventory.json
```

A capture command succeeding means every requested outcome was recorded. It
**does not** mean all Go tests or S08 gates passed. The report retains the test
exit code and each source outcome. Fresh output paths are required; no existing
capture is overwritten.

Verify archive integrity before inspecting an extraction:

```python
import hashlib, json, tarfile
from pathlib import Path
p = Path("tools/s08/results/baseline-review")
m = json.loads((p / "manifest.json").read_bytes())
assert hashlib.sha256((p / m["archive"]).read_bytes()).hexdigest() == m["archive_sha256"]
with tarfile.open(p / m["archive"], "r:xz") as archive:
    actual = {}
    for member in archive:
        assert member.isfile()
        raw = archive.extractfile(member).read()
        actual[member.name] = {"bytes": len(raw), "sha256": hashlib.sha256(raw).hexdigest()}
    assert actual == m["files"]
```
